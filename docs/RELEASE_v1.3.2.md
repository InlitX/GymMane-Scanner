# GymMane Scanner 1.3.2

Tag: `v1.3.2` · Android versionCode: `6`

## Was ist neu?

- Updates direkt in der App: automatische Prüfung alle 24 Stunden und manuelle Prüfung in Einstellungen.
- APK-Download mit Fortschritt, Dateiprüfung und Übergabe an den Android-Installer.
- Einmalige Versionshinweise nach einem Update.
- Einheitliche, dezente Animationen für Bildschirmwechsel, Listen, Dialoge, Buttons und wechselnde Inhalte.
- Unterstützung für die Systemeinstellung „Animationen entfernen“.
- Onboarding, Deutsch/Englisch und ein eigener Einstellungsbildschirm.
- Lebensmittel mit unverändertem Import-JSON über den Android-Teilen-Dialog an GymMane übergeben.

## What’s new?

- In-app updates: automatic checks every 24 hours and manual checks in Settings.
- APK download progress, file validation and handoff to the Android installer.
- One-time release notes after an update.
- Consistent, subtle motion for navigation, lists, dialogs, buttons and changing content.
- Support for the system’s reduced-motion setting.
- Onboarding, German/English language selection and a dedicated Settings screen.
- Share foods with GymMane using the unchanged JSON import format and Android share sheet.
